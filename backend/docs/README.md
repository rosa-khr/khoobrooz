# مستندات Backend

این پوشه مستندات اجرایی مربوط به `Laravel Backend` را نگهداری می‌کند.

## وضعیت فعلی

در محیط فعلی local، ابزارهای زیر نصب نبودند:

```text
php
composer
```

به همین دلیل scaffold واقعی Laravel هنوز انجام نشده است. بعد از آماده شدن ابزارها، Laravel طبق سند `laravel-scaffold.md` داخل همین فولدر `backend/` ساخته می‌شود.

## مستندات

- `laravel-scaffold.md`: مراحل ساخت Laravel
- `foundation-checklist.md`: چک‌لیست فاز foundation
- `database-contracts.md`: قراردادهای مشترک Database و Migration
- `testing-standard.md`: استاندارد تست Backend

# Banner Library

Banner assets kept for future Khoobrooz page sections and service banners.

## Files

- `trade-port-hero-dark-natural.jpg`: current optimized homepage hero. Same dark navy port mood, compressed for smoother page load and scroll.
- `trade-port-hero-dark-natural.png`: previous larger homepage hero source.
- `container-clearance-closeup.jpg`: current homepage clearance-section image. Close-up container terminal composition with calmer right-side space for the translucent content card.
- `trade-process-background-natural.jpg`: current homepage clearance-section image. Brighter, warmer version with less navy cast.
- `trade-process-background.png`: original generated trade operations image before natural color adjustment.
- `trade-port-hero-dark.png`: previous dark generated hero before natural post-processing.
- `trade-port-hero-calm.png`: previous calmer daylight homepage hero option with more negative space for text.
- `trade-port-hero-generated.png`: previous homepage hero option. More detailed and busier; keep as an alternate archive.
- `port-terminal-wide.webp`: previous homepage hero option. Useful for services overview, import/export, and international shipping sections.
- `global-logistics-ship-plane.webp`: good option for logistics, cargo, import from China, and service cards.
- `cargo-ship-top-view-watermarked.webp`: has visible Freepik watermark. Keep for internal reference only unless a licensed clean version is provided.
- `trade-banner-01.webp` to `trade-banner-05.webp`: small source images. Use only for thumbnails, drafts, or low-priority visual placeholders.

## Usage Notes

- Prefer `trade-port-hero-dark-natural.png` for the homepage hero.
- Use a restrained overlay when placing Persian text over logistics images.
- Do not use watermarked images on the public production website.

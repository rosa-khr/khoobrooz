# 05 Commerce Payment Agent Run

## Output Goal

Plan Khoobrooz digital document sales and future Zarinpal integration without implementing real payment too early.

## Commerce Role

Commercial files and documents are a secondary revenue path. They should support the service business, not replace it.

Recommended first product categories:

- نمونه اسناد واردات
- نمونه اسناد صادرات
- قراردادهای تجاری
- چک‌لیست‌ها
- فایل‌های اکسل محاسبات
- مکاتبات تجاری انگلیسی

1. نمونه پروفرما اینویس
2. نمونه پکینگ لیست

4. نمونه قرارداد صادراتی

9. اکسل محاسبه هزینه ترخیص

## Product Page Requirements

Each product should have:

- Title
- Category
- Short description
- Detailed description
- Price
- File type
- Update date
- Preview/sample
- What is included
- Who it is for
- Purchase CTA
- Support note
- Related service CTA

## Zarinpal Future Flow

Future payment flow:

1. User selects product.
2. User goes to checkout.
3. Site creates payment request.
4. User pays through Zarinpal.
5. Zarinpal redirects to callback URL.
6. Site verifies payment.
7. User sees success or failure page.
8. Successful order receives secure download access.

## Required Before Real Payment

Need from user:

- Zarinpal merchant details
- Whether Enamad is available
- Product prices
- File delivery method
- Refund/update policy
- Customer support method
- Whether users need accounts
- Whether email/SMS receipt is required

## Phase 1 Boundary

In phase 1, product pages can exist without real payment.

Use one of these temporary CTAs:

- درخواست خرید فایل
- دریافت راهنمای خرید
- اطلاع‌رسانی زمان انتشار
- تماس برای تهیه فایل

## Metadata Pattern

Service title pattern:

- `نام خدمت | خوبروز`

Article title pattern:

- `موضوع مقاله + عبارت کاربردی | خوبروز`

Meta description rules:

- Persian
- 135 to 160 characters when practical
- Include the main keyword naturally
- Mention practical value and next action
- Avoid exaggerated claims

## Multilingual SEO Plan

Phase 1 can launch in Persian only, but content IDs and routes should allow future versions:

- `/fa/services/customs-clearance`
- `/en/services/customs-clearance`
- `/ar/services/customs-clearance`

When translating, do not translate regulatory claims blindly. Use localized SEO titles, descriptions, slugs, and `hreflang`.

# 03 UI UX Agent Run

## Output Goal

Define the first visual and experience direction for Khoobrooz before frontend implementation.

## Design Direction

Khoobrooz should feel:

- formal
- trustworthy
- commercial
- calm
- service-first
- custom, not template-based
- fully responsive
- mobile-first

Use the brand palette:

- Primary: `#0B1F3A`
- Accent: `#C9A24A`
- Secondary: `#0F766E`
- Background: `#F7F8FA`
- Surface: `#FFFFFF`
- Text: `#1F2937`

## Responsive Standard

Design must support:

- mobile
- tablet
- laptop
- desktop
- wide desktop

Mobile-first behavior is required. Header, services dropdown, CTA buttons, service cards, article layouts, product grids, and forms must stay readable and stable on small screens.

## Typography Standard

Preferred Persian font:

- Dana, if licensed and available for web use

Fallback stack:

- Dana
- IRANSans
- Vazirmatn
- system-ui
- sans-serif

Use readable Persian typography with consistent line-height. Avoid decorative fonts and overly large headings inside cards or compact UI sections.

## Homepage Wireframe

Recommended order:

1. Header
2. Hero
3. Main services
4. Consultation CTA
5. Why Khoobrooz
6. Service process
7. Knowledge base preview
8. Commercial document preview
9. FAQ
10. Contact CTA
11. Footer

## Header UX

Header should include:

- Khoobrooz logo/name
- Compact main navigation
- Services dropdown
- Education/knowledge dropdown
- Khoobrooz/about dropdown
- Language switcher placeholder
- Primary CTA: دریافت مشاوره

Mobile navigation:

- Use collapsible groups
- Keep خدمات as the most prominent group
- Keep CTA visible
- Avoid overcrowding the first mobile screen

Mobile CTA routing:

- On customs clearance pages, use `09103060396` until a separate clearance line is confirmed.
- For general WhatsApp/contact actions, use the user's personal/general line `09103060396`.

## Hero UX

Hero must immediately communicate:

- Trade services
- Customs clearance and import/export support
- Formal credibility
- Clear next action

Recommended hero CTA hierarchy:

1. دریافت مشاوره
2. مشاهده خدمات

Avoid a generic marketing hero. The first viewport should feel like a serious business service interface.

## Service Cards

Service cards should be scannable and compact.

Priority cards:

- ترخیص کالا
- ثبت سفارش واردات
- واردات کالا
- واردات از چین
- کارگو چین
- حمل و نقل بین‌المللی

Each card should include:

- Service name
- One short practical line
- Link to service page

## Article UX

Article pages should include:

- Clear H1
- Updated date for sensitive content
- Table of contents for long content
- Readable Persian typography
- Related service CTA
- Related documents
- FAQ

## Product UX

Document product pages should include:

- Product title
- File type
- Price
- What is included
- Preview/sample area
- Purchase CTA
- Support note
- Related service CTA

## Before Design Approval

Need from user:

- Logo status
- Dana font license or webfont availability
- Whether the brand should feel more corporate or more premium
- Which CTA is primary: consultation, cost inquiry, or WhatsApp
- Whether language switcher should be visible in phase 1

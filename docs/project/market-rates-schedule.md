# زمان‌بندی بروزرسانی نرخ‌های بازار

صفحه نرخ ارز و API داخلی سایت چند نوع نرخ را جدا نمایش می‌دهند:

- نرخ رسمی بانک مرکزی
- نرخ حواله مرکز مبادله
- حواله کالای اساسی و دارو
- نرخ بازار برای برآورد غیررسمی
- طلا، فلزات و سکه

## مسیرها

- صفحه سایت: `/markets/currency-rates`
- API داخلی برای کران: `/api/market-rates`
- منبع نرخ رسمی: بانک مرکزی
- منبع نرخ حواله و بازار در نسخه فعلی فقط از طریق سرویس backend خوانده می‌شود.

## زمان‌بندی پیشنهادی

روی سرور، کران باید هر روز ساعت ۹ صبح و ۳ بعدازظهر به وقت ایران اجرا شود.

اگر timezone سرور قابل تنظیم است:

```cron
TZ=Asia/Tehran
0 9,15 * * * curl -fsS https://YOUR_DOMAIN.com/api/market-rates >/dev/null
```

اگر timezone سرور UTC است، زمان ایران UTC+03:30 است:

```cron
30 5,11 * * * curl -fsS https://YOUR_DOMAIN.com/api/market-rates >/dev/null
```

## نکته اجرایی

- مقدار `YOUR_DOMAIN.com` باید با دامنه نهایی سایت جایگزین شود.
- API داخلی داده‌ها را نرمال می‌کند و خروجی را در گروه‌های رسمی، حواله، بازار، فلزات و سکه برمی‌گرداند.
- اتصال مستقیم بانک مرکزی در محیط سرور ممکن است به دلیل محافظت/کپچا نیازمند منبع رسمی جایگزین، API قراردادی یا ذخیره‌سازی از بک‌اند باشد.
- در صورت تغییر آدرس provider خارجی، مقدار `TGJU_API_URL` فقط در محیط سرویس backend قابل تنظیم است.
- این کران برای گرم‌کردن کش و بررسی منظم منبع است. اگر در آینده دیتابیس اضافه شود، همین مسیر می‌تواند داده‌ها را ذخیره کند.
